# Cerámicas Martin i Ross

A modern web application for Cerámicas Martin i Ross, a Colombian artisanal ceramics factory based in Cali.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
